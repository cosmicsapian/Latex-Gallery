# Galley — your LaTeX compiler

Open `index.html` on a laptop to try it right away.

## Put it online for free (one time, about 3 minutes)

1. On github.com, create a new **public** repository called `galley`.
2. Click **Add file → Upload files**, drop in every file from this folder, and commit.
3. Go to **Settings → Pages**, set **Branch** to `main` and folder `/ (root)`, then **Save**.
4. After a minute your app is live at `https://YOUR-USERNAME.github.io/galley/`.

## Install it on phone and iPad

- **iPhone / iPad:** open the link in Safari → Share → **Add to Home Screen**.
- **Android:** open the link in Chrome → ⋮ menu → **Install app**.

After the first visit it opens instantly, even before the network answers.

## Good to know

- **No account.** Compiling uses the free public TeX Live service at latex.ytotech.com
  (pdfLaTeX, XeLaTeX, LuaLaTeX; BibTeX/Biber run automatically).
- **Your files** go to that server only when you press Compile. To keep everything on your own
  machine, run your own copy (Docker image, see github.com/YtoTech/latex-on-http) and paste its
  address in ⋯ → Compile server.
- **History** is stored on each device. Use Files → Download .zip / Open .zip to move a project
  between devices or to and from Overleaf.
